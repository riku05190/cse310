# Overview

As a software engineer, my goal is to deepen my understanding of object-oriented programming (OOP) principles and build clean, scalable command-line applications in Java. To advance my software development skills, I developed this Student Gradebook application to practice structuring modular code, managing in-memory state with collections, and writing robust, maintainable logic.

This software is an interactive, console-based Student Gradebook System designed to manage student academic records. It allows users to register students, record and validate numerical scores, compute grade point averages, assign standard letter grades (A–F), determine pass/fail status, and display organized academic summaries for all registered students.

The purpose of writing this software was to master core Java syntax and object-oriented fundamentals. This includes utilizing mutable and immutable variables, arithmetic and comparison expressions, conditional validation, iterative loops, custom functions/methods, class inheritance via an abstract base class (`User`), and efficient collection data structures (`ArrayList` and `HashMap`).
